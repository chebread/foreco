# foreco
`foreco` is a program that recommends foods for you.

## Feature

### Arguments
```shell
foreco # Recommend a random food.

foreco korean # Recommend random Korean food.

foreco vegan # Recommend random vegan food.
```

### Options
```shell
foreco --help, -h # Show this help message.

foreco --version, -V # Show version information.
```

## Installation
You can install `foreco` with Homebrew:
```shell
brew tap chebread/foreco

brew install foreco
```
